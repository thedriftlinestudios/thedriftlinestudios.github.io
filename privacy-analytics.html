Driftline Analytics: Privacy Policy

Driftline Studios · Last updated 22 September 2026

Driftline Studios operates the YouTube channels Edge & Ledger and The Receipts Room. This policy covers our internal reporting tool, Driftline Analytics, which uses YouTube API Services. Our publishing tool, Driftline Studios Uploader, is a separate application with its own privacy policy.

What the application does

Driftline Analytics is a private, single-operator tool. It reads the performance reports of the two YouTube channels we own, so that we can see how our own videos are doing. It is not offered to the public, has no user accounts, and no one other than the owner of those channels can sign in to it. It cannot upload, edit or delete anything.

What data it uses

  • It requests a single permission scope, https://www.googleapis.com/auth/yt-analytics.readonly, which allows viewing YouTube Analytics reports for the channels that sign in to it.
  • It reads aggregated reports for our own channels only: for example views, watch time, average view duration, subscribers gained and lost, how viewers found a video, how long they kept watching, thumbnail impressions and click-through rate.
  • These reports are totals. They do not identify any individual viewer, and the tool does not request or store any viewer’s personal data.
  • It does not read data belonging to any channel we do not own.

How the data is stored

Report data and the owner’s authorisation credential are stored privately by Driftline Studios and are not shared with, sold to, or disclosed to any third party. The authorisation is re-confirmed each time reports are fetched; if it cannot be re-confirmed for 30 days, the stored report data is deleted.

YouTube API Services

The application uses YouTube API Services. By using it you are agreeing to be bound by the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.

Revoking access

Access granted to this application can be revoked at any time from the Google security settings page. Stored report data is then deleted within 30 days.
