Privacy Policy

Driftline Studios · Last updated 5 September 2026

Driftline Studios operates the YouTube channels Edge & Ledger and The Receipts Room. This policy covers our internal publishing tool, Driftline Studios Uploader, which uses YouTube API Services.

What the application does

Driftline Studios Uploader is a private, single-operator tool. It uploads videos that we produce ourselves to YouTube channels that we own. It is not offered to the public, has no user accounts, and no one other than the channel owner can sign in to it.

What data we collect

We do not collect, store, sell, or share the personal data of any third party. The application has no users other than the owner of the channels.

  • It stores one OAuth credential belonging to the channel owner, used solely to upload to that owner's own channels.
  • That credential is held locally, is not transmitted to any third party, and is not included in any published code.
  • It requests a single permission scope, https://www.googleapis.com/auth/youtube.upload, which allows uploading a video and setting its thumbnail. It cannot read viewer data, comments, or analytics.
  • No viewer, subscriber, or audience data is accessed, retrieved, or stored.

YouTube API Services

The application uses YouTube API Services. By using it you are agreeing to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access granted to this application can be revoked at any time from the Google security settings page.

Data retention

Stored authorisation credentials are deleted when access is revoked or when they expire. As no third-party personal data is collected, there is no third-party data to retain or delete.
